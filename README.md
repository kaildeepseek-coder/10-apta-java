# Кинотеатрды басқару жүйесі

## Жоба туралы

Бұл Java жобасы кинотеатр жұмысын қарапайым түрде модельдейді.
Бағдарлама фильмдер мен сеанстар туралы ақпаратты көрсетеді, клиенттерге
билеттерді брондауға мүмкіндік береді және билеттер үшін төлем жасауды
имитациялайды.

Жоба объектіге бағытталған бағдарламалау қағидаларын және SOLID
принциптерін көрсету мақсатында жасалған.

## Жобаның мақсаты

Кинотеатрдағы негізгі процестерді автоматтандырудың қарапайым үлгісін
құру: - фильмдер мен сеанстарды тіркеу; - сеанстар туралы ақпаратты
көрсету; - клиентке билет брондау; - бос орын санын жаңарту; - қолма-қол
ақша немесе банк картасы арқылы төлем жасауды көрсету.

## Қолданылған технологиялар

-   **Java** --- бағдарламалау тілі;
-   **ArrayList және List** --- сеанстар мен билеттер тізімін сақтау;
-   **Интерфейстер** --- брондау және төлем әрекеттерін сипаттау;
-   **OOP** --- инкапсуляция, композиция және полиморфизм.

## Жоба құрылымы

Бағдарлама `Main.java` файлының ішінде орналасқан және келесі
интерфейстер мен кластардан тұрады:

  -----------------------------------------------------------------------
  Класс / интерфейс                   Міндеті
  ----------------------------------- -----------------------------------
  `Bookable`                          Билет брондау әрекетін анықтайды

  `Payable`                           Төлем жасау әрекетін анықтайды

  `Movie`                             Фильм атауын, жанрын және ұзақтығын
                                      сақтайды

  `Session`                           Фильм сеансы, уақыты, бағасы және
                                      бос орын санын сақтайды

  `Customer`                          Клиент туралы ақпаратты сақтайды

  `Ticket`                            Клиент пен сеансты байланыстыратын
                                      билет

  `Cinema`                            Сеанстарды және брондалған
                                      билеттерді басқарады

  `CashPayment`                       Қолма-қол төлемді жүзеге асырады

  `CardPayment`                       Банк картасымен төлемді жүзеге
                                      асырады

  `PaymentService`                    Таңдалған төлем тәсілін орындайды

  `Main`                              Бағдарламаны іске қосады және
                                      негізгі әрекеттерді көрсетеді
  -----------------------------------------------------------------------

## SOLID принциптерінің қолданылуы

### 1. SRP --- Single Responsibility Principle

Әр класс бір негізгі міндет атқарады. Мысалы, `Movie` фильм деректерін
сақтайды, `Ticket` билет туралы ақпаратты көрсетеді, ал `PaymentService`
төлем процесін басқарады.

### 2. OCP --- Open/Closed Principle

`Payable` интерфейсін іске асыратын жаңа төлем түрлерін қосуға болады.
Мысалы, болашақта `OnlinePayment` класын қосу үшін `PaymentService`
класын қайта жазудың қажеті жоқ.

### 3. LSP --- Liskov Substitution Principle

`CashPayment` және `CardPayment` кластары `Payable` интерфейсін іске
асырады. Сондықтан олардың кез келгенін `PaymentService` ішінде бірдей
қолдануға болады.

### 4. ISP --- Interface Segregation Principle

`Bookable` және `Payable` интерфейстері бөлек міндеттерді сипаттайды.
Кластар өздеріне қажет емес әдістерді іске асыруға мәжбүр болмайды.

### 5. DIP --- Dependency Inversion Principle

`PaymentService` нақты `CashPayment` немесе `CardPayment` класына емес,
`Payable` абстракциясына тәуелді. Төлем тәсілі конструктор арқылы
беріледі.

## Бағдарламаның жұмыс істеу тәртібі

1.  Екі фильм объектісі құрылады: «Аватар» және «Титаник».
2.  Әр фильм үшін сеанс уақыты, билет бағасы және бос орын саны
    белгіленеді.
3.  `Cinema` объектісіне сеанстар қосылады.
4.  Сеанстар туралы ақпарат экранға шығарылады.
5.  Екі клиентке билет объектілері жасалып, брондау орындалады.
6.  Брондалған билеттер тізімі көрсетіледі.
7.  Бір билетке қолма-қол, екіншісіне картамен төлем жасалады.
8.  Брондаудан кейін қалған бос орындар қайта көрсетіледі.

## Іске қосу нұсқаулығы

### 1. Java орнатылғанын тексеру

Терминалда келесі командаларды орындаңыз:

``` bash
java -version
javac -version
```

### 2. Файл атауы

Кодтағы `public class Main` болғандықтан, файл атауы **Main.java** болуы
керек.

### 3. Компиляциялау

``` bash
javac Main.java
```

### 4. Бағдарламаны іске қосу

``` bash
java Main
```

## Күтілетін нәтиже

Бағдарлама орындалған кезде консольде: - кинотеатр атауы мен фильм
сеанстары; - билет брондау нәтижелері; - брондалған билеттер; - төлем
түрлері мен төлем нәтижелері; - әр сеанста қалған бос орындар; -
бағдарламаның аяқталғаны туралы хабарлама көрсетіледі.

## Қорытынды

Бұл жоба кинотеатрды басқарудың негізгі процестерін Java тілінде
модельдейді. Кластар мен интерфейстер міндеттерді бөлуге, ал полиморфизм
төлем тәсілдерін икемді қолдануға мүмкіндік береді. Жоба SOLID
принциптерінің негізгі идеяларын шағын практикалық мысал арқылы
көрсетеді.
